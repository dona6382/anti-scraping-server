# 🚀 INSTANT START

## One Command to Rule Them All

```bash
chmod +x GO.sh && ./GO.sh
```

That's it! The server will start automatically.

---

## What It Does

1. ✅ Installs all dependencies
2. ✅ Checks your environment
3. ✅ Creates configuration files
4. ✅ Compiles TypeScript
5. ✅ Starts the development server

---

## After Starting

Open your browser to:
- 🌐 **Test UI**: http://localhost:3000/public/index.html
- 💚 **Health Check**: http://localhost:3000/health
- 📚 **API**: http://localhost:3000

## Troubleshooting

If you see TypeScript errors:
```bash
# Don't worry! The DTO validation works without class-validator
npm run start:dev
```

If port 3000 is busy:
```bash
# Change port in .env file
echo "PORT=3001" >> .env
```

---

## Stop Server

Press `Ctrl+C` in the terminal
