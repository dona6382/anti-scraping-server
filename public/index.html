🛡️ Anti-Scraping Server Test Interface

ℹ️ Information

This page demonstrates various anti-scraping techniques implemented in the NestJS server:

  • Rate Limiting: Limits the number of requests from an IP
  • User-Agent Filtering: Blocks suspicious or known bot user agents
  • IP Blacklisting: Blocks requests from blacklisted IPs
  • Honeypot Fields: Hidden fields that only bots would fill
  • reCAPTCHA v3: Google's invisible bot detection
  • Headless Browser Detection: Detects automated browsers

⚠️ Testing Tips

  • Open Developer Tools to see network requests and console logs
  • Try using curl or Postman to see how the server blocks non-browser clients
  • Use a VPN to test IP-based restrictions
  • Try automated testing tools like Puppeteer to trigger headless detection
  • Fill in the honeypot fields (if you can find them) to trigger bot detection
